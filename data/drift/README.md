# Drift windows

Generated by `make_drift_windows.py` with a fixed seed (`config.DRIFT_SEED`). No LLM calls.

| File | Size | Contents |
|---|---|---|
| `templates.json` | — | Rewording templates seeded from `golden_dataset.json` questions and topics |
| `reference.jsonl` | 100 | Usual week: 40% hours, 30% insurance, 20% cancellation, 10% vaccines; 80% front desk |
| `control.jsonl` | 100 | Another usual week from the same mix. PSI vs reference must stay < 0.1 |
| `current.jsonl` | 100 | Shifted week: dengue questions, telehealth (not in `knowledge.txt`), longer queries, more clinician lookups |

Why not use the golden dataset directly: 8 questions is too few for PSI (about 5–10 per bucket are needed), and it is a curated test set, not a sample of traffic. The golden set seeds the windows and stays the fixed test set for regression.
